#  Real-Time Chat Application

A full-stack real-time chat application that enables users to connect and communicate instantly. The application provides secure authentication using Email OTP and Phone OTP verification, contact management, one-to-one messaging, media sharing, message notifications, typing indicators, and read receipts.

---

##  Features

###  Authentication & Authorization

- Login and registration using Email OTP
- Login and registration using Phone OTP
- Secure OTP verification
- Protected routes
- User session management
- Authentication and authorization implemented throughout the application

###  User Management

- View user profile
- Update profile information
- Search users
- Add users to contacts
- Manage contact list

###  Real-Time Chat

- One-to-one messaging
- Instant message delivery using Socket.IO
- Real-time communication
- Typing indicators
- Read receipts (Mark as Read)
- Online/Offline user status

###  Media Sharing

- Send and receive images
- Share media files in conversations
- Real-time media delivery

###  Notifications

- Real-time message notifications
- New message alerts
- Instant updates without page refresh

---

### Frontend

### Authentication

- Email OTP Authentication
- Phone OTP Authentication

---

##  Workflow

1. User signs up or logs in using Email OTP or Phone OTP.
2. OTP verification is completed securely.
3. User can access and update their profile.
4. Users can search and add other users to their contacts.
5. Users can start one-to-one conversations.
6. Messages are delivered instantly through Socket.IO.
7. Typing indicators show when another user is typing.
8. Read receipts indicate when messages have been seen.
9. Users receive real-time notifications for new messages.
10. Images and media can be shared within conversations.
